# Data Science & AI Handbook

A complete, browsable study handbook for the Data Science & AI programme, organised class by class, plus basic-to-advanced learning sessions for non-technical learners.

**Open it:** download this folder and open `index.html` in any browser, or deploy the folder as a static site (Netlify Drop, GitHub Pages).

## What's inside

### Learning sessions (basic → advanced, non-tech friendly)
S1 Advanced Excel · S2 SQL · S3 Power BI · S4 Tableau · S5 Python · S6 Machine Learning · S7 AI, GenAI & Agentic AI · S8 Tools for Data Science & AI (ChatGPT, Claude, Gemini, Copilot, Grok, Perplexity, Lovable, NotebookLM, Cursor…) · S9 Interview Q&A · S10 Reverse Engineering · S11 Automation on Data · S12 Storytelling, Portfolio & Career

### Files
- `pdf/` — 17 PDFs with clickable contents: the complete handbook, the Building Blocks handbook, one PDF per learning session, ML illustrated notes, case studies and resolutions.
- `files/Excel_Basic_to_Advanced.xlsx` — 22-sheet practice workbook (1,593 live formulas, fictional sample data).
- `source/` — build scripts and content sources (`python3 build.py` then `python3 make_pdfs.py`).

## Notes
- Case-study questions are summarised in our own words and solved independently; no LMS recordings, attachments or login links are included.
- Sample data in the Excel workbook is fictional.
- Video links (Simplilearn and others) are YouTube searches so they stay valid as channels update.
