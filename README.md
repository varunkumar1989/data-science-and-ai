# SkillNavora Data Science & AI Learning Library

This repository is the version-control home for the original SkillNavora Data Science & AI learning materials prepared for Varun Kumar.

## Scope

- Excel, SQL, Power BI, Tableau, Python, machine learning, text mining, MLOps, generative AI and agentic AI.
- Ethical reverse engineering and Forward Deployed Engineering (FDE).
- Original study explanations, practice prompts and curated public learning resources.
- No private LMS recordings, attachments, login links or copied course answer keys.

## Publishing notes

The site source is maintained separately for hosted deployment. Generated PDFs and artwork are release-style learning artifacts; they are kept out of the source repository unless explicitly prepared for a public release.

## Learning workflow

1. Start with a track roadmap.
2. Use each session page to identify the topics covered.
3. Build a small reproducible example.
4. Use AI for practice and review, then verify claims with data and official documentation.
