Frames, shapes and text

  • A frame (F) is a screen or a container. Pick a preset in the right panel (iPhone 16, Android Compact, Desktop 1440). Frames can be nested and can clip content.
  • A group (Ctrl+G) only bundles layers; it has no layout of its own. Prefer frames with auto layout.
  • Shapes (R, O, L, P) take fills (solid, gradient, image), strokes, corner radius and effects (drop shadow, blur).
  • Text (T): set font, size, line height and letter spacing in the Design panel; use Auto width for labels and Fixed width for paragraphs.

The 8-point grid

Use spacing and sizes in multiples of 8 (4 for small gaps): 8, 16, 24, 32, 48, 64. Add a layout grid to a frame (Design panel → Layout grid → 8 px grid or columns: 4 columns for mobile, 12 for desktop) so everything lines up.

Python
# A type scale (ratio 1.25 from 16 px) and an 8-point spacing scale: the numbers you put into text styles and auto layout gaps
base, ratio = 16, 1.25
type_scale = {name: round(base * ratio ** i) for i, name in enumerate(["Body", "H6", "H5", "H4", "H3", "H2", "H1"])}
spacing = [4, 8, 12, 16, 24, 32, 48, 64]
print("Type scale (px):", type_scale)
print("Spacing tokens (px):", spacing)
Output

Spacing tokens (px): [4, 8, 12, 16, 24, 32, 48, 64]

Colour contrast (accessibility)

Text must be readable: WCAG asks for a contrast ratio of at least 4.5:1 for normal text and 3:1 for large text. Figma shows contrast in plugins such as Stark or A11y – Color Contrast Checker; this is the formula they use:

Python
def lum(hex_):
    r, g, b = (int(hex_[i:i + 2], 16) / 255 for i in (1, 3, 5))
    f = lambda c: c / 12.92 if c <= 0.03928 else ((c + 0.055) / 1.055) ** 2.4
    return 0.2126 * f(r) + 0.7152 * f(g) + 0.0722 * f(b)
def contrast(fg, bg):
    a, b = sorted([lum(fg), lum(bg)], reverse=True); return (a + 0.05) / (b + 0.05)
for fg, bg in [("#FFFFFF", "#6C4CF5"), ("#9CA3AF", "#FFFFFF"), ("#17142E", "#F3F0FF"), ("#FFFFFF", "#12B5A6")]:
    r = contrast(fg, bg); print(f"{fg} on {bg}: {r:4.2f}:1  ->", "PASS normal text" if r >= 4.5 else "PASS large text only" if r >= 3 else "FAIL")
Output
#FFFFFF on #6C4CF5: 5.26:1  -> PASS normal text
#9CA3AF on #FFFFFF: 2.54:1  -> FAIL
#17142E on #F3F0FF: 15.92:1  -> PASS normal text
#FFFFFF on #12B5A6: 2.57:1  -> FAIL

Light grey text on white and white text on bright teal fail even the 3:1 large-text rule, so darken those colours (for example teal #0E7C72) until the checker passes.

Auto layout: responsive design

Auto layout (Shift + A) turns a frame into a flexbox: children stack horizontally or vertically with a fixed gap and padding, and the frame grows or shrinks with its content.

Step by stepBuild a responsive button
  1. Type "Get started" (T). Select it and press Shift + A: a frame wraps the text.
  2. Set padding 12 (vertical) × 24 (horizontal), corner radius 8, fill your brand colour, text white.
  3. Set the frame to Hug both ways: change the text to "Start your free trial" and the button grows.
  4. Put three buttons in a vertical auto layout with gap 12 and set each to Fill container: they all stretch to the same width.

Constraints (for frames without auto layout) decide how a layer moves when its parent resizes: Left, Right, Left & Right (stretch), Centre, Scale. Use them for headers and floating buttons.

Components, variants and properties

A component (Ctrl + Alt + K) is a master; instances are copies that update when the master changes.

Feature What it does Example
Variants Group related components into one set with properties Button: Type = Primary/Secondary, State = Default/Hover/Disabled, Size = S/M/L
Boolean property Show/hide a layer "Has icon" on/off
Text property Edit the label from the instance panel Button label
Instance swap property Swap a nested component Choose the icon
Overrides Change text, colour or images on one instance without detaching it One red "Delete" button
Libraries Publish components to the whole team (Assets panel) Company design system
Python
from itertools import product
props = {"Type": ["Primary", "Secondary", "Ghost"], "State": ["Default", "Hover", "Disabled"], "Size": ["S", "M", "L"]}
variants = list(product(*props.values()))
print(len(variants), "variants in the Button set, e.g.", ", ".join("/".join(v) for v in variants[:3]))
print("Without variant properties you would manage", len(variants), "separate components.")
Output
27 variants in the Button set, e.g. Primary/Default/S, Primary/Default/M, Primary/Default/L
Without variant properties you would manage 27 separate components.

Styles and variables (design tokens)

  • Styles: saved colour, text, effect and grid styles you apply with one click.
  • Variables (collections and modes): named values (colour, number, string, boolean) such as color/bg/surface or space/16. A collection can have modes like Light and Dark or Brand A and Brand B: switch a frame's mode and every bound colour changes.
  • Bind spacing, radius and colours to variables so a redesign is one edit, and developers get the same token names in Dev Mode.

Prototyping

Switch to the Prototype tab:

  1. Select a button, drag the blue handle to the target frame: this creates a connection.
  2. Set the trigger (On click, On drag, While hovering, After delay, Key/Gamepad) and the action (Navigate to, Open overlay, Swap overlay, Back, Scroll to, Open link, Set variable).
  3. Choose the animation: Instant, Dissolve, Move in/out, Push, Slide, or Smart Animate (matches layers with the same name across frames and animates the difference).
  4. Mark a flow starting point and press Present (Ctrl + Alt + Enter) or share the prototype link.

Advanced: interactive components (a toggle that switches its own variant on click), variables and conditionals in prototypes (a counter, a cart total, "if logged in"), and scroll behaviour (fixed headers, horizontal carousels).

Project for data roles: design a KPI dashboard before building it

Designing the dashboard in Figma first saves hours in Power BI or Tableau:

  1. Frame: Desktop 1440 × 1024, 12-column grid, 24 px gutters.
  2. Header: title, date range picker, filters (Region, Segment) as components.
  3. KPI cards: a component with variants (Up/Down/Neutral) and text properties for label, value and change.

What n8n is

n8n ("n-eight-n", from nodemation) connects apps and data with visual workflows. Each workflow starts with a trigger (a form is submitted, a schedule fires, a webhook is called) and passes data through nodes that read, transform and send it. Compared with Zapier and Make, n8n can be self-hosted (your data stays on your server), lets you write code in any step, and has strong AI-agent nodes.

Zapier Make n8n
Hosting Cloud only Cloud only Cloud or self-hosted (Docker, npm)
Pricing unit Tasks (each step) Operations Workflow executions (cloud); free to self-host under its fair-code licence
Code Code steps (limited) Limited Full JavaScript/Python Code node, npm packages when self-hosted
Best for Quick app-to-app zaps Visual scenarios with routers Data pipelines, AI agents, privacy-sensitive automations

The editor and the core ideas

Concept Meaning
Workflow The canvas of connected nodes; Active workflows run on their trigger
Trigger node Starts the run: Manual, Schedule, Webhook, n8n Form, Chat, app triggers (Gmail, Google Sheets, Typeform, Stripe…)
Node One step: an app action, a core utility, or an AI node
Credentials Saved, encrypted logins/API keys (OAuth for Google, Slack, etc.), reused by nodes
Items Data flows as a list of JSON items; most nodes run once per item
Expressions {{ $json.email }}, {{ $now.toFormat('yyyy-MM-dd') }}, {{ $('Form').item.json.name }} to use data from earlier nodes
Executions History of every run with the input/output of each node, for debugging and re-running

Items: the most important idea

Every node receives and outputs an array of items, each { "json": { … } }. If a Google Sheets node returns 25 rows, the next Slack node runs 25 times, once per item, unless you aggregate first.

Python
import json
items = [{"json": {"name": "Asha", "email": "asha@example.com", "city": "Pune", "score": 82}},
         {"json": {"name": "Ravi", "email": "ravi@example.com", "city": "Delhi", "score": 45}},
         {"json": {"name": "Meera", "email": "meera@example.com", "city": "Pune", "score": 91}}]
# IF node: score >= 60 goes to the "true" branch
true_branch = [i for i in items if i["json"]["score"] >= 60]
# Edit Fields (Set) node: keep and add fields
shaped = [{"json": {"lead": i["json"]["name"], "email": i["json"]["email"], "priority": "hot" if i["json"]["score"] >= 90 else "warm"}} for i in true_branch]
# Aggregate node: many items -> one item with a list
aggregated = {"json": {"leads": [s["json"]["lead"] for s in shaped], "count": len(shaped)}}
print(json.dumps(shaped, indent=1)); print(aggregated)

Aggregate / Summarize Many items → one (list, sum, count, group by)

Wait Pause for a time or until a webhook/form resumes the run

Code JavaScript or Python over all items or each item
Date & Time, Crypto, XML/HTML, Extract From File, Convert to File Utilities

Code node example (JavaScript, "Run once for all items")

JAVASCRIPT
// Clean phone numbers and drop duplicates by email
const seen = new Set();
return $input.all()
  .filter(item => { const e = item.json.email.toLowerCase().trim(); if (seen.has(e)) return false; seen.add(e); return true; })
  .map(item => ({ json: { ...item.json, phone: String(item.json.phone || '').replace(/\D/g, '').slice(-10) } }));

The Python version of the same idea (Code node → Language: Python) uses _input.all() and returns a list of dicts with a json key.

HTTP Request: calling an API

Python
# What an HTTP Request node sends and how you map the answer back into items
request = {"method": "GET", "url": "https://api.example.com/v1/orders", "qs": {"status": "paid", "limit": 2},
           "headers": {"Authorization": "Bearer {{ $credentials.apiKey }}"}}
response = {"data": [{"id": 101, "amount": 2499, "city": "Pune"}, {"id": 102, "amount": 899, "city": "Delhi"}], "next": None}
items = [{"json": o} for o in response["data"]]          # Split Out on "data"
print(request["method"], request["url"], request["qs"]); print(items)
Output
GET https://api.example.com/v1/orders {'status': 'paid', 'limit': 2}
[{'json': {'id': 101, 'amount': 2499, 'city': 'Pune'}}, {'json': {'id': 102, 'amount': 899, 'city': 'Delhi'}}]

Tips: use Authentication → Predefined credential type when n8n has the app, otherwise Generic credential (header auth, OAuth2); turn on Pagination for APIs with next links; add Retry on fail (Settings) for flaky APIs.

Reliability: errors, retries and scheduling

  • Settings per node: Retry on fail (tries and wait), Continue on fail / error output branch, Always output data.
  • Error workflow: Workflow settings → Error workflow → pick a workflow that starts with Error Trigger and sends you a Slack/WhatsApp/email alert with the failed node and message.
  • Schedule Trigger: every X minutes, daily at 09:00 IST (set the workflow time zone to Asia/Kolkata), or a cron expression 0 9 * * 1-5.
  • Pin data while building: freeze a node's output so you do not call the API on every test.
  • Environment safety: keep secrets in credentials, never in Code nodes; restrict who can edit workflows; use separate dev and prod instances for important flows.

AI agents in n8n

The AI Agent node runs a loop: a chat model reads the goal, decides which tool to call, reads the result and continues until it can answer.

Other AI building blocks: Basic LLM Chain, Text Classifier, Information Extractor (pull fields from emails or PDFs into JSON), Summarization Chain, Sentiment Analysis, Embeddings + Vector Store nodes (Pinecone, Qdrant, Supabase, PGVector, in-memory) for RAG, and the Chat Trigger for a hosted chat window.

n8n and MCP

  • MCP Client Tool: lets an n8n agent use tools from any MCP server.
  • MCP Server Trigger: exposes your n8n workflows as MCP tools, so Claude or other MCP clients can call them (for example "create a lead in our CRM").

Key takeaways

Interview cornerQuestions you may be asked

Q: n8n vs Zapier vs Make? Zapier is the simplest for app-to-app automations; Make adds visual branching and data mapping; n8n adds self-hosting, full code steps, sub-workflows and strong AI-agent features, which suits data and AI teams.

Q: How do you make an automation reliable? Retries with backoff, error branches and an error workflow with alerts, idempotent steps (check before creating), rate-limit batching, logging executions, separate test and production, and secrets in credentials.

Q: How would you build a support bot on company documents in n8n? An indexing workflow that loads documents, splits them, embeds them and stores them in a vector store; a chat workflow with Chat Trigger, an AI Agent with a chat model, memory and the vector store as a retrieval tool, with sources in answers and a human-handover path.
