The vocabulary every analyst uses

DefinitionCore terms

Workbook: the file (.xlsx). One workbook holds many worksheets. Worksheet (sheet): one grid of rows and columns inside a workbook. Cell: one box where a row and a column meet, for example C4. Cell reference (address): column letter + row number, such as C4. Used inside formulas to point at cells. Range: a rectangle of cells written as first:last, for example A1:C10 (3 columns × 10 rows = 30 cells). Formula: anything that starts with = and calculates a result, such as =B4*12. Function: a built-in, named formula that takes inputs (arguments), such as =SUM(B2:B6). Argument: an input you give a function, separated by commas: =ROUND(B2, 1) has two arguments.

Watch outThe 15-digit trap

Excel keeps only 15 significant digits. If you type a 16-digit card number or a long ID, the last digits turn into zeros. Store long IDs, phone numbers, PIN codes and account numbers as text (format the column as Text first, or start the entry with an apostrophe ').

Structured data: the single most important habit

Excel will do almost anything, but it can only analyse data that is laid out as a clean table. Analysts call this structured or tidy data.

Step by stepThe six rules of a structured table
  1. One header row at the top, with a unique, short name for every column.
  2. One record per row, for example one order, one employee or one day.
  3. One kind of information per column: dates only in the date column, numbers only in the amount column.
  4. No blank rows or blank columns inside the table.
  5. No merged cells and no totals typed in the middle of the data.
  6. Raw values, not decorations: write Delhi, not Delhi ✔ (checked).

Excel properties: what makes a workbook "smart"

These behaviours make Excel more than a calculator:

  1. Automatic recalculation: change an input and every dependent formula updates instantly (Formulas → Calculation Options can switch this to Manual for huge files; press F9 to recalculate).
  2. Relative references: copy =B2*12 down and it becomes =B3*12, =B4*12 automatically (Lesson 4 covers $ to lock references).
  3. AutoFill: drag the small square (fill handle) at the bottom-right of a selection to continue patterns: Jan → Feb → Mar, 1, 2, 3, Mon, Tue, dates and formulas.
  4. Flash Fill (Ctrl + E): type one or two examples of a pattern (such as first names taken from full names) and Excel fills the rest.
  5. Excel Tables (Ctrl + T): turn a range into a named table that expands automatically, keeps formatting, and allows readable formulas like =SUM(Sales[Amount]).
  6. File properties: File → Info shows the author, size, last-modified date and lets you inspect the workbook for hidden data before sharing.

Quick quiz6 questions · tap an answer to check it

1. A cell shows 18,000, but the formula bar shows =B4*12. What is inside the cell?

Answer: B. The cell displays the result; the formula bar shows what is stored. This cell stores a formula.

2. How many cells are in the range B2:D5?

Answer: C. Columns B, C, D = 3 columns; rows 2 to 5 = 4 rows; 3 × 4 = 12 cells.

3. Which of these breaks the rules of structured data?

Answer: B. Region should be its own column, with the value repeated on every row. Merged headings make the data impossible to sort, filter or pivot.

4. Why does SUM ignore some numbers imported from a CSV file?

Answer: B. Numbers stored as text are skipped by SUM. Convert them with Text to Columns, VALUE() or Convert to Number.

5. What does Excel store when you type the date 27-04-2026?

Answer: B. Dates are numbers formatted to look like dates. That is why date arithmetic works.

6. Which shortcut turns a range into an Excel Table?

Answer: C. Ctrl + T creates a Table. Ctrl + E is Flash Fill, Ctrl + 1 opens Format Cells, Ctrl + Shift + L toggles filters.

Interview cornerQuestions you may be asked

Q: What is the difference between a formula and a function? A formula is any expression that starts with = (for example =A2*B2). A function is a named, built-in calculation used inside formulas (for example SUM, VLOOKUP). Every function is used in a formula, but not every formula uses a function.

Q: How does Excel store dates, and why does it matter? As serial numbers (days since 1-Jan-1900; times are fractions of a day). It means you can subtract dates to get durations, add days to a date, and sort dates correctly. If a date is stored as text, none of that works.

Q: What makes data "analysis-ready"? One header row, one record per row, one data type per column, no blank rows or merged cells, no subtotals mixed into the data, and consistent spelling of categories.

DefinitionTwo words people mix up

Summary

Key takeaways
  • Formula = any calculation starting with =; function = a named calculation such as SUM.
  • Order: brackets, power, multiply/divide, add/subtract, join, compare. In Excel -2^2 = 4.
  • $ locks a reference; F4 cycles relative → absolute → mixed. Mixed references build 2-D tables with one formula.
  • COUNT counts numbers; COUNTA counts non-empty; COUNTBLANK counts empty.
  • SUMIFS(sum_range, criteria_range, criteria, …) and COUNTIFS answer most business questions.
  • Criteria with operators go in quotes and join cell values with &: ">="&H1.
  • SUBTOTAL(109,…) sums only visible rows; AGGREGATE can also ignore errors.

Interview cornerQuestions you may be asked

Q: What is the difference between COUNT, COUNTA and COUNTBLANK? COUNT counts numeric cells, COUNTA counts every non-empty cell (including text and formulas returning ""), COUNTBLANK counts empty cells and cells containing "".

Q: When would you use a mixed reference? When a formula is copied in two directions and must keep either the row or the column fixed, for example a price × quantity grid or a commission table: =$A2*B$1.

Q: Why use SUMIFS instead of SUMIF? SUMIFS supports multiple conditions, has a consistent argument order (sum range first), and works for one condition too, so one pattern covers every case.

Q: How do you total only visible rows after filtering? Use SUBTOTAL(109, range) or AGGREGATE(9, 5, range); the Table Total Row does this automatically.

Common mistakesOrder matters in nested IF and IFS

Excel stops at the first TRUE condition. If you test A2>=60 first, a mark of 92 returns "C". Always test from the highest threshold to the lowest (or lowest to highest with <). In IFS, end with TRUE, "default" so values that match nothing do not return #N/A.

Common mistakesThe four classic VLOOKUP mistakes
  1. Forgetting FALSE: the default is approximate match, which silently returns a wrong row for unsorted data.
  2. Not locking the table: A2:E7 copied down becomes A3:E8, so the last rows are missed. Use $A$2:$E$7 or a Table name.
  3. Hard-coded column numbers: inserting a column inside the table changes which column 4 means. Use MATCH for the column number, or XLOOKUP.
  4. Key not in the first column: VLOOKUP cannot look to the left (use INDEX + MATCH or XLOOKUP).

Summary

Key takeaways
  • Lookups bring columns from one table into another through a shared key, like a SQL left join.
  • VLOOKUP: key in the first column, column number counted from 1, FALSE for exact match, lock the table with $.
  • Approximate match (TRUE / match_mode −1) is for sorted bands: tax slabs, commissions, grades.
  • XLOOKUP is exact by default, looks left, has a built-in "not found" value, returns several columns and can search from the end.
  • INDEX returns a value at a position; MATCH finds the position. Together they do reverse and two-way lookups in any Excel version.
  • Most #N/A errors come from missing keys, spaces, or number-vs-text mismatches.

Interview cornerQuestions you may be asked

Q: What are the limitations of VLOOKUP and how do you overcome them? It cannot look left, it defaults to approximate match, it breaks when columns are inserted (hard-coded index), and it returns only the first match. Use XLOOKUP or INDEX + MATCH, and FILTER for multiple matches.

Q: Why is INDEX + MATCH considered more flexible than VLOOKUP? The lookup and return ranges are separate, so it can look left, it is not affected by inserted columns, it supports two-way lookups, and it can be faster on large sheets because it only reads the columns it needs.

Q: How would you look up a value using two criteria? XLOOKUP(1,(range1=x)*(range2=y),return_range), INDEX/MATCH with the same multiplied condition, or a helper column that concatenates the two keys.

What a pivot table does

A pivot table groups rows by one or more fields and summarises a number for each group (sum, count, average…). It is the fastest way to answer "how much, by what?" questions, with no formulas.

The pivot cache, Refresh and Refresh All

A pivot table does not read your sheet directly. When you create it, Excel copies the data into a hidden pivot cache, and the pivot reads from that cache. This is why pivots are fast, and also why they do not update automatically when the data changes.

Why "Power" tools?

Formulas and pivots are great until the same cleaning has to be repeated every month, the data has several related tables, or it grows past a million rows. The Power tools solve exactly these problems, and they are the same engines used in Power BI, so everything you learn here transfers directly.

Power Query: repeatable cleaning

Power Query (Data → Get & Transform Data) imports data and records every cleaning step you click. Next month, put the new file in place and click Refresh: all steps run again automatically.

Merge (join) and Append (union)

  • Merge Queries = a lookup or SQL JOIN. Choose the two tables, click the matching key column in each, and choose the join kind: Left Outer (all rows from the first table, matching rows from the second: like XLOOKUP), Inner (only matches), Full Outer, Left Anti (rows with no match: great for finding missing products). Then expand the new column to pick which fields to bring in.
  • Append Queries = SQL UNION ALL: stack January, February and March files that share the same columns.

The M language

Every step is written in M, Power Query's formula language. View it in Home → Advanced Editor:

Power Query M
let
    Source = Csv.Document(File.Contents("C:\Data\superstore_sales.csv"), [Delimiter=",", Encoding=65001]),
    Promoted = Table.PromoteHeaders(Source, [PromoteAllScalars=true]),
    Typed = Table.TransformColumnTypes(Promoted, {{"order_date", type date}, {"sales", type number}, {"profit", type number}}),
    AddedYear = Table.AddColumn(Typed, "Year", each Date.Year([order_date]), Int64.Type),
    HighDiscount = Table.AddColumn(AddedYear, "Discount band", each if [discount] > 0.2 then "High" else "Normal"),
    Grouped = Table.Group(HighDiscount, {"region", "Year"}, {{"Sales", each List.Sum([sales]), type number}})
in
    Grouped

Power Pivot and the Data Model

The Data Model stores tables inside the workbook in a compressed, columnar engine (VertiPaq, the same engine as Power BI). It handles millions of rows and lets one pivot table use several related tables, without VLOOKUPs.

Step by stepBuild a small model
  1. Load Sales, Products and Customers with Power Query → Close & Load To → Only Create Connection + Add this data to the Data Model.
  2. Data → Manage Data Model (Power Pivot window) → Diagram View.
  3. Drag Sales[product_id] onto Products[product_id] and Sales[customer_id] onto Customers[customer_id] to create one-to-many relationships (Lesson 2 of the SQL track explains why).
  4. Insert → PivotTable → From Data Model. You can now put Products[category] in Rows and Sales[sales] in Values: the relationship connects them.

DAX measures in Power Pivot

Measures are formulas that calculate on the fly for whatever is in the pivot (filter context). In Power Pivot → Measures → New Measure (or type in the calculation area):

DAX
Total Sales := SUM ( Sales[sales] )
Total Profit := SUM ( Sales[profit] )
Profit Margin := DIVIDE ( [Total Profit], [Total Sales] )
Orders := DISTINCTCOUNT ( Sales[order_id] )
Technology Sales := CALCULATE ( [Total Sales], Products[category] = "Technology" )

Unlike pivot calculated fields (Lesson 8), Profit Margin here is always correct at every level, and DISTINCTCOUNT is built in. DAX is covered in depth in the Power BI track (Lesson 4).

Interview cornerQuestions you may be asked

Q: What is Power Query and why use it? Excel's (and Power BI's) ETL tool. It connects to many sources, applies recorded, repeatable transformations (types, splits, merges, unpivot, grouping) and refreshes with one click, which reduces manual errors.

Q: What is the difference between Merge and Append? Merge adds columns from another table by matching keys (a join); Append adds rows from tables with the same structure (a union).

Q: What is the Data Model and when do you need it? An in-memory columnar database inside Excel for related tables and large data. Use it when you have several tables, need distinct counts, or exceed normal sheet limits; it also supports DAX measures.

Q: How would you find the break-even price? Build the profit formula and use Goal Seek to set profit to 0 by changing price, or solve algebraically: price = variable cost + fixed costs ÷ units.
