What is programming?

A program is a set of precise instructions a computer follows. Computers only understand machine code (0s and 1s), so we write instructions in a programming language that humans can read, and a translator turns them into something the machine can run.

Compiled vs interpreted

Compiled (C, C++, Rust, Go) Interpreted (Python, JavaScript, R)
How it runs Whole program translated to machine code before running Translated and executed line by line while running
Speed Usually faster at run time Slower per operation, much faster to develop
Errors Many caught before running Some appear only when that line runs
Output A separate executable file Source file runs under an interpreter

Python is usually called interpreted. In reality CPython (the standard version) first compiles your code to bytecode (.pyc files) and then a virtual machine executes it. Python code that needs speed calls libraries written in C (NumPy, pandas), so data work is fast anyway.

Jupyter notebooks

A Jupyter notebook (.ipynb) mixes code cells, Markdown cells (text, headings, images) and outputs (tables, charts) in one document. It is the standard tool for exploring data and sharing analysis. The name comes from Julia, Python and R.

The kernel

The kernel is the Python process behind the notebook. Variables you create stay in its memory until you restart it. Cells can be run in any order, which is flexible but dangerous: a notebook can look right while depending on a cell you deleted. Before sharing, always Restart Kernel and Run All to prove the notebook works top to bottom.

Mutable vs immutable

  • Immutable: cannot be changed after creation: int, float, str, bool, tuple, frozenset. "Changing" creates a new object.
  • Mutable: can be changed in place: list, dict, set.
Python
s = "data"
try:
    s[0] = "D"                     # strings are immutable
except TypeError as e:
    print("Error:", e)
s2 = "D" + s[1:]                    # build a new string instead
print(s2, "| id changed:", id(s) != id(s2))
Output
Error: 'str' object does not support item assignment
Data | id changed: True

Watch outFloating-point surprises

Computers store decimals in binary, so 0.1 + 0.2 is 0.30000000000000004. For money use decimal.Decimal (or integers of paise); for comparisons use math.isclose(a, b) or abs(a - b) < tolerance. Python's round() rounds halves to the nearest even number (round(2.5) = 2), unlike Excel's ROUND.

Python

import math; print(math.isclose(0.1 + 0.2, 0.3))
Output
0.3
True

f-strings: the modern way to format

Put f before the quotes and {expression:format} inside:

Python
name, qty, price, share = "Asha", 3, 1234.5678, 0.2345
print(f"{name} bought {qty} items")
print(f"Price: {price:.2f}")                 # 2 decimals
print(f"Price: {price:,.2f}")                # thousands separator
print(f"Share: {share:.1%}")                 # percentage
print(f"ID: {qty:03d}")                       # zero-padded to 3 digits
print(f"[{name:<10}] [{name:>10}] [{name:^10}]")        # left, right, centre in width 10
print(f"{price:>12,.1f}|")                    # right-aligned width 12
print(f"{qty * price:,.2f}  {qty = }")        # expressions work; {x = } prints name and value
print(f"{1234567:,}  {255:#x}  {255:b}  {0.000123:.2e}")
Output
Asha bought 3 items
Price: 1234.57
Price: 1,234.57
Share: 23.4%
ID: 003
[Asha      ] [      Asha] [   Asha   ]
     1,234.6|
3,703.70  qty = 3
1,234,567  0xff  11111111  1.23e-04

Interview cornerQuestions you may be asked

Interview cornerQuestions you may be asked

Q: How do you reverse a string in Python? s[::-1] (slice with step −1) or "".join(reversed(s)).

Q: Why use "".join(list) instead of += in a loop? Strings are immutable; each += creates a new string (quadratic time). Building a list and joining once is linear.

Q: Difference between find and index? find returns −1 if the substring is missing; index raises ValueError.

Q: What does // do with negative numbers? Floors toward minus infinity: -7 // 2 = -4, and -7 % 3 = 2, so (a // b) * b + a % b == a always holds.

match: structural pattern matching (3.10+)

match compares one value with several patterns: a clean alternative to a long chain of == tests.

Python
def describe_status(code):
    match code:
        case 200 | 201:
            return "success"
        case 301 | 302:
            return "redirect"
        case 404:
            return "not found"
        case int(c) if 500 <= c < 600:
            return "server error"
        case _:
            return "unknown"
print([describe_status(c) for c in (200, 404, 503, 999)])
Output
['success', 'not found', 'server error', 'unknown']

def handle(command):

def loan_precheck(age, income, existing_emi, credit_score):

Key takeaways

Mutability, aliasing and copying

A variable holds a reference to a list. Assigning a list to another name does not copy it.

Python
a = [1, 2, 3]
b = a                      # b is another name for the SAME list
b.append(4)
print(a, b, a is b)
c = a.copy()               # a real (shallow) copy; also list(a) or a[:]
c.append(99)
print(a, c, a is c)
Output
[1, 2, 3, 4] [1, 2, 3, 4] True
[1, 2, 3, 4] [1, 2, 3, 4, 99] False
Python
import copy
grid = [[1, 2], [3, 4]]
shallow = grid.copy(); deep = copy.deepcopy(grid)
grid[0][0] = 100
print(shallow, deep)       # shallow copy sees the change in the inner list; deep copy does not
Output
[[100, 2], [3, 4]] [[1, 2], [3, 4]]
Watch outMutable default arguments and `[[0] * 3] * 3`

[[0] * 3] * 3 creates three references to the same inner list; changing one row changes all. Build grids with a comprehension: [[0] * 3 for _ in range(3)]. Never use a list as a default function argument (def f(x, items=[])): use None and create the list inside (Lesson 9).

What is a dictionary?

A dictionary (dict) maps keys to values: look up by name instead of by position. It keeps insertion order (Python 3.7+), and lookups are O(1) on average.
